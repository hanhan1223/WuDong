# 安全规范检查

检查项目是否符合安全开发要求。

## 检查项

### 1. 认证授权

- [ ] JWT 鉴权中间件是否全局生效
- [ ] 三级权限是否正确区分：游客/普通用户/运营管理员
- [ ] Token 过期时间是否合理
- [ ] 敏感接口是否有权限校验

### 2. 接口防护

- [ ] 是否有速率限制中间件（防刷接口）
- [ ] 秒杀/抢购场景是否使用分布式锁（防超卖）
- [ ] 是否有 CORS 配置
- [ ] 是否有请求体大小限制

### 3. 数据安全

- [ ] 密码是否使用 bcrypt 加密存储
- [ ] SQL 查询是否使用参数化（ORM）
- [ ] 是否有 XSS 防护（富文本过滤）
- [ ] 是否有 CSRF 防护
- [ ] 敏感信息（身份证、手机号）是否脱敏展示

### 4. 日志审计

- [ ] 是否有全链路请求/响应日志
- [ ] 异常是否统一捕获并标准化返回
- [ ] 关键操作（支付、退款）是否有审计日志
- [ ] 操作日志是否记录操作人、IP、时间

### 5. 内容安全

- [ ] 用户上传内容是否经过审核
- [ ] 敏感词过滤是否生效
- [ ] 图片/视频是否进行内容安全检测

### 6. HTTPS & 传输安全

- [ ] 生产环境是否强制 HTTPS
- [ ] API 响应是否设置安全头
- [ ] 敏感数据传输是否加密

## OWASP Top 10 快速检查

1. 注入：检查 SQL/NoSQL/命令注入风险
2. 失效认证：检查认证机制
3. 敏感数据泄露：检查数据加密
4. XXE：检查 XML 解析配置
5. 访问控制：检查权限校验
6. 安全配置：检查默认配置
7. XSS：检查输入输出编码
8. 不安全反序列化：检查序列化使用
9. 使用含漏洞组件：检查依赖版本
10. 日志和监控：检查日志完整性

## 输出格式

按风险等级输出：

- 🔴 高风险：必须立即修复
- 🟡 中风险：建议尽快修复
- 🔵 低风险：可后续优化
