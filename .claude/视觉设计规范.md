# 乌东文旅"衣食住行"综合服务平台 视觉设计规范

## 1. 设计理念

**苗寨有银，文化有纹** —— 以贵州苗族文化为灵感来源，将银饰的冷冽光泽、蜡染的靛蓝、刺绣的暖色调融入现代数字界面。

### 品牌关键词

| 关键词   | 视觉表现                         |
| -------- | -------------------------------- |
| 民族文化 | 银饰、蜡染、刺绣纹样、苗银冷色调 |
| 山野自然 | 梯田绿、远山青、暖阳橙           |
| 数字现代 | 干净留白、扁平化、几何线条       |
| 信任温暖 | 暖色调辅助色、亲切文案、圆润元素 |

## 6. 按钮组件

### 按钮类型

| 类型     | 样式         | 用途                             |
| -------- | ------------ | -------------------------------- |
| 主按钮   | 实心苗银蓝   | 主要操作（立即购买、提交、确认） |
| 次按钮   | 描边苗银蓝   | 次要操作（取消、返回）           |
| 文字按钮 | 无背景无边框 | 辅助操作（查看更多）             |
| 危险按钮 | 实心错误色   | 删除、清空                       |
| 禁用按钮 | 灰色背景     | 不可点击                         |

### 按钮尺寸

| 尺寸 | 高度 | 内边距 | 字号 | 圆角 |
| ---- | ---- | ------ | ---- | ---- |
| 小   | 28px | 12px   | 12px | 4px  |
| 默认 | 36px | 16px   | 14px | 6px  |
| 中   | 40px | 20px   | 14px | 8px  |
| 大   | 48px | 24px   | 16px | 8px  |

### 按钮状态

| 状态 | 样式变化                       |
| ---- | ------------------------------ |
| 默认 | 实心 `#1F5FA8`，文字 `#FFFFFF` |
| 悬浮 | 背景 `#3B7BC5`（亮度 +10%）    |
| 按下 | 背景 `#0E3D75`（亮度 -10%）    |
| 禁用 | 背景 `#BFBFBF`，文字 `#FFFFFF` |

## 8. 动效规范

### 动画时长

| 类型 | 时长  | 用途                   |

| 名称 | 函数                           | 用途     |

## 11. 苗族文化元素使用规范

### 可使用的文化元素

| 元素       | 使用场景     | 使用方式               |
| ---------- | ------------ | ---------------------- |
| 苗银       | 品牌主色     | 整页通用               |
| 蜡染靛蓝   | 装饰点缀     | 背景图案、分割线       |
| 苗绣橙     | 强调色       | 按钮、价格、徽章       |
| 苗银纹样   | Logo、装饰   | 不超过画面 20%         |
| 苗年节庆   | 插画         | Banner、启动页主体展示 |
| 苗族长桌宴 | 食模块主视觉 | Banner 配图            |
| 苗寨木屋   | 住模块主视觉 | 详情页配图             |
| 梯田       | 行模块主视觉 | Banner 配图            |

### 设计原则

- 文化元素应自然融入界面，避免生硬堆砌
- 传统纹样可进行现代化几何简化
- 色彩使用需符合品牌色系统
